# 区域高亮地图（map_ai）

在浏览器里用的地图工具：**输入地名 → 半透明高亮它的真实范围**，可以一次高亮很多块、颜色互不重复，用来比较形状、大小与相互距离。附带标准/卫星双底图、手绘描边、多点测距、两点路径规划，以及「功能」菜单里的**地图艺术海报导出**。

纯前端 + 零 npm 依赖（Leaflet 已本地化到 `vendor/`），不需要构建步骤。

---

## 快速开始

```bash
cd map_ai
node serve.mjs          # 或双击 启动.bat（会顺便打开浏览器）
```

浏览器打开 <http://localhost:8080>。**不启动服务也能用**：直接双击 `index.html` 即可，只是此时无法配置高德 key、且部分跨源请求会被浏览器拦掉，所以推荐走 `serve.mjs`。

`serve.mjs` 做三件事：静态文件服务 + `/api/*` 反向代理（amap / datav / osrm / photon / esri / nominatim / overpass）+ `/api/settings` 保存高德 key。服务只监听 `127.0.0.1`，局域网其它机器访问不到；高德的 key 由服务端注入，**不会出现在前端代码与 git 里**。

## 要不要注册高德 key

不配 key 也够用，功能差别如下：

| 能力 | 免 key | 配 key |
|---|---|---|
| 国/省/市/区县 行政区高亮（含面积、周长、按粒度批量高亮下级） | ✅ 阿里云 DataV | ✅ |
| 手绘任意区域、多点测距 | ✅ | ✅ |
| 两点路径规划 | ✅ OSRM（境外引擎，国内路网偏粗）+ Photon 地址解析 | ✅ 高德驾车/步行/骑行/公交，含国内真实路网与耗时 |
| 城市地图艺术海报导出 | ✅ 走免 key 的标准栅格瓦片 | ✅ |
| 兴趣点（学校/小区/公园）搜索与**真实轮廓** | ❌ 只能打点 + 提示改用描边 | ✅ 取决于接口是否返回 AOI 边界字段 |

配 key 方法：

1. 打开 <https://lbs.amap.com> → 注册 → 实名认证（个人开发者免费配额足够）。
2. 控制台 → 创建应用 → 添加 key → 服务平台选 **Web服务**（不是 Web端 JS API）。
3. 回到本页，点顶栏 **设置** → 粘贴 key → **保存**，状态栏立刻变成「高德 key 已启用」，无需重启。
   - 勾选 **显示** 可核对粘贴内容；点 **删除 key** 即清空并回到免 key 模式。
   - 不想用页面时也可以手动：复制 `config.example.json` 为 `config.json` 填 `amapKey` 后重启 `serve.mjs`。
4. 想看接口到底给了哪些字段（尤其有没有轮廓）：`node scripts/probe-amap.mjs 华南农业大学 广州`，完整响应会写到 `.amap-probe.json`。

### key 的隐私边界

- 明文只存在于「你粘贴 → 这一次本机 POST」的瞬间；服务端写进同目录 `config.json`（已在 `.gitignore` 里，`git log -S` 全历史无明文），转发高德请求时才注入。
- 前端只拿到掩码（`xxxx…yyyy` 形式），页面 DOM、控制台、截图、git 历史都不会出现完整 key。
- 写接口 `POST /api/settings` 有三重门禁：仅接受回环地址、必须带自定义头 `X-Requested-With: map_ai`（跨站简单表单带不上且不放行预检）、Origin 必须同端口；`serve.mjs` 本身只 `listen` 在 `127.0.0.1`，局域网其它机器访问不到。
- 换电脑或删掉 `config.json` 即彻底清除；不放心也可以随时点 **删除 key** 再重新粘贴。

## 操作说明

**搜索高亮** — 顶部输入框输入地名，下拉里点一条或按回车。结果会标注类型：`[行政区·区县级]` / `[POI·高校]` / `[手绘]`。

**粒度（批量高亮下级）** — 面板顶部「粒度」下拉。选了级别后再高亮某个行政区，就把它的下级一次各上一色：广东省 → 下级市（21 个）/ 下两级区县（122 个）；广州市 → 下级区县（11 个）。勾上「叠显父级轮廓」可以把父级边界垫在下面，实现父子跨级搭配显示。同一范围换粒度会自动只替换上一批，不影响你另外高亮的区域。
- 下拉里的「下级乡镇街道」是**置灰**的：实测高德 `config/district` 对街道级返回的边界串长度为 0，DataV 最细到区县级，画不出面。区县级区域会额外给出「列出街道/镇中心点」按钮，退一步用中心点把街道摆出来。
- 区域数超过 24 块时不再逐块贴名称标签（会糊成一片），名称仍在右侧面板列表里；超过 12 块时距离矩阵也改为提示而不生成 n² 表格。

**右键** —
- 在高亮区域上右键：`取消高亮`、`仅保留这一块`、`复制名称与面积`；
- 在空白处右键：`设为路径起点/终点`、`从这里开始绘制区域`、`测距：从此处开始`、`高亮此处所属行政区`（后者需 key）。最后一项是**二级菜单**，把这块地方从国家到区县逐级列出来让你挑一级；如果反查到了乡镇街道，会把「街道」放在最前面并置灰说明拿不到轮廓，同时给「高亮所属区县」「只标记中心点」「沿卫星影像描边」三个出口。

**左键永远穿透** — 高亮面放在独立图层且设为非交互，所以在高亮区域里选点、描边、测距都不受影响。

**绘制区域** — 顶栏「绘制区域」→ 左键沿边界逐点点击（状态栏实时显示面积）→ 右键或回车闭合 → 命名。`Ctrl+Z` 撤销上一个点，`Esc` 退出。建议先切「卫星」图照着描。

**测距** — 顶栏「测距」→ 左键逐点点击，每段与合计直线距离都会标在图上；`Esc` 清除。

**路径** — 顶栏「路径」→ 起终点**填地名**（支持「广州石化小学，大门」这种「主体，附属点」写法，输入时会防抖出候选下拉，按距另一端就近排序）→ 选驾车/步行/骑行/公交 → 规划。也可以直接在地图上右键取点：设为起点/终点后，输入框显示反查到的地名而不是坐标，地图上落下绿「起」/红「终」圆牌与地名标签，圆牌可拖动改点。

**功能** — 顶栏「功能」是后续所有新能力的统一入口，点开是一个下拉菜单，以后加功能只往这个列表里挂一条，不再往界面上塞控件。

**城市地图艺术海报**（「功能」→ 第一项）— 填城市/区县名点「取景」：本地行政索引反查 adcode → DataV 取真实轮廓 → Leaflet `fitBounds` 按取景框四边留白把轮廓正好嵌进去，之后仍可自由平移、滚轮微调入画范围。
- 比例 7 档：`4:3 / 16:9 / 1:1 / 3:4 / 9:16 / 1.414:1 / 1:1.414`；清晰度 4 档：`网页 1600 / 高清 3000 / 超清 4500 / 巨幅 6000`（指取景框短边像素）；配色 3 套：`琥珀 / 纸墨 / 暗夜`。另有「叠行政界线」「按城市轮廓裁切」「留白边与细框」三个开关，标题与副标题默认为空、取景时自动填城市名与「经纬度 · 省 · 中国」。
- **成图不是屏幕截图**。按取景框反推整数缩放级 `z`，再按 `z` 级 1:1 逐块抓高德矢量瓦片合成（上限 420 块瓦片、3000 万像素），所以页面上的弹窗、面板、高亮色块都不会混进图里，清晰度也不受显示器限制。
- **艺术化处理**：逐像素分类 → 连通块过滤（文字、POI 图标、路牌这类紧凑小块整块抹掉，细长道路与大面绿地水系保留）→ 空洞回填 → 只对绿地与水系做形态学闭运算（白色字描边常把实色豁开一条通向外部底色的细缝，先缝住缝、再回头看一遍，压在实色上的整块字就成了可识别的孤岛）→ 按配色重映射并做四邻域混色。画面最终只剩底纹、水网、路网与绿地。
- 排版：大字距（逐字手排）标题 + 自动转大写的小字副标题 + 细线边框与内缩留白，标题用 `strokeText` 纸色光晕压图，不铺底色药丸。产出 `海报_城市_宽x高.png`。
- 城市级取景一般落在 z11、区县街道级在 z15；「预览小图」只用于确认构图，导出会按所选清晰度重画。

**其他** — 「全部区域」缩放到能看见所有高亮；「清除」清空；右侧面板每块区域有 `定位 / 复制 / 删除`，鼠标悬停会加深该块；≥2 块时面板下方给出**两两质心直线距离矩阵**。高亮集合存在 localStorage，刷新后自动恢复。

快捷键：`Esc` 退出当前工具 / `Enter` 闭合描边 / `Ctrl+Z` 撤销顶点。

## 数据源与坐标系

- 底图瓦片：高德 `webrd0x style=8`（标准）、`webst0x style=6`（卫星）+ `style=8`（路网注记叠加），备用 Esri World Imagery。
- 行政区面：阿里云 DataV.GeoAtlas `geo.datav.aliyun.com/areas_v3/bound/{adcode}[_full].json`，免费、允许跨源。**最细到区县级**（乡镇街道接口不开放），所以更小的范围请用「绘制区域」。
- 名称→adcode 索引：`data/admin-index.json`，由 `scripts/build-admin-index.mjs` 从 modood/Administrative-divisions-of-China（GB/T 2260）抓取生成，共 3343 条（国 1 / 省 34 / 市 333 / 区县 2975）。重新生成：`node scripts/build-admin-index.mjs`。
- 底图与 DataV 边界同为 **GCJ-02**，实测在 15 级下区界与珠江岸线、道路贴合，无需纠偏。OSRM / Photon 是 **WGS84**，代码里经 `src/geom/coortransform.js` 转换后再画，所以路线能压在路网上。
- 面积用球面多边形公式（`R=6371008.8`）本地算，不依赖任何接口：天河区 137 km²（官方 137.39）、广州 11 个区县合计 7415 km²（官方 7434，误差 0.25%）。

## 已知限制（说实话）

- 本机网络下 **Nominatim / Overpass / tile.openstreetmap.org 全部不可达**（前者超时、Overpass 返回 406、OSM 瓦片 DNS 失败），含中国数据的 Overpass 镜像也没找到可用的，所以细粒度边界只能指望高德。
- 用个人 key 实测：`place/text`、`place/detail`（v3/v5）、`place/around` **都不返回轮廓字段**；`config/district` 的 `polyline` **只到区县级**，乡镇街道能识别（`level=street`）但边界串长度为 0。因此校园、企业、小区这一级改用 `regeo` 的 `aois[].area` 画**等面积圆**——位置与面积是真的、形状是近似的，标签和提示里都写明了；街道/村这一级拿不到面积也拿不到轮廓，程序会弹窗说明实测依据并引导改用「绘制区域」描边，不会假装成功。
- 高德 key 的个人配额有限，且 `restapi` 对无 referer 的服务端调用有 QPS 限制；批量抓取请自行加间隔。
- `启动.bat` 固定打开 8080 端口；若在 `config.json` 改了 `port`，请手动访问对应端口。
- 手绘区域只存顶点，不保存影像底图快照；换设备需要同步的话得自己导出。
- 高亮色板预设 8 色，超出后按黄金角色相自动生成，仍保证互不相同。
- 海报在**极密集取景**（区县级 z15 往上）下仍会留下零星 POI 白色光带与小段橙色地名残迹：高德把一部分 POI 名直接画成与主干道同色，像素级分类无法可靠区分「路」和「字」，强行收紧会把路网一起吃掉。城市级（z11~z12）取景基本干净。
- 海报底图来自高德栅格瓦片，**个人打印、装饰、自用没有问题**；要公开发布或商用售卖请先确认底图授权，代码不提供绕开授权的手段。
